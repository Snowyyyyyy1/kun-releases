# kun-releases

Version manifest for [Kun](https://github.com/Snowyyyyyy1/Kun), read by the app's update check.

Kun's own repository is private, and an anonymous read of a private repository's releases returns
404. Rather than ship a token inside the distributed app — a token in a published package is a
published token — the release workflow mirrors the release list here, where it can be read without
credentials.

`releases.json` carries only what the check needs: version, channel, publish time and a link back
to the release page. It is generated by CI from `gh release list`; edits made by hand are
overwritten on the next release.

The download links point at the private repository, so following one requires a GitHub account with
access. The manifest tells you a version exists; it does not distribute it.
